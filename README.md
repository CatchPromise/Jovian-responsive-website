About The Project

Jovian is a frontend development project created to practise and strengthen my skills in building websites with HTML and CSS.

The project focuses on structuring web content, styling page elements, and implementing responsive layouts for different screen sizes.

Technologies Used

* HTML5
* CSS3

Features

* Structured HTML layout
* Custom CSS styling
* Responsive design for mobile, tablet, and desktop screens
* Flexible page layout
* Navigation and footer sections

Responsive Design

The website is designed to adapt to different viewport sizes, providing a usable experience across:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

Getting Started

To run this project locally:

1. Clone the repository:

git clone https://github.com/CatchPromise/Jovian-responsive-website.git

2. Open the project folder in VS Code.
3. Open index.html in your browser.
